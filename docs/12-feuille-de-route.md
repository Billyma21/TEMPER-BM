# Feuille de route

Sprints de deux semaines. Chaque sprint se termine par une démo, une revue des droits et un compte rendu dans `docs/reunions`.

| Sprint | Objectif | Livrables vérifiables |
|---|---|---|
| 0 (fait) | Fondations | Monorepo, schéma 146 tables et migration, seed, 41 rôles et tests, API auth / droits / audit / pointage / monde, front Bureau + Monde + borne, docs, réunions |
| 1 | Socle API | Modules Nest par domaine (CRUD générique sûr : liste filtrée, détail, création, modification), pagination, tri, recherche, erreurs normalisées, tests d intégration par rôle, OpenAPI, i18n |
| 2 | Socle UI | Bibliothèque de composants, tableau de données, tiroir de détail, formulaires zod, boîte de validation, notifications, MFA (enrôlement TOTP, WebAuthn), Playwright |
| 3 | Organisation, RH, accès | Organigramme, fiches employés, onboarding / offboarding, badges, zones, règles, visiteurs, évacuation, SSO |
| 4 | Temps | Plannings 3x8, moteur de journées, anomalies, corrections, congés, absences, capteurs, charge k6 |
| 5 | Paie et clôture | Relevés, double validation, export secrétariat social, jours fériés, soldes |
| 6 | Production | Recettes versionnées, OF, tablette de ligne, consommations par lot, lots et généalogie, TRS, moteur de quêtes |
| 7 | Qualité et maintenance | HACCP, contrôles, NC, CAPA, libération, rappels, GMAO, permis, MQTT machines |
| 8 | Stocks, outils, achats | Réceptions, FEFO, inventaires, transferts, outils et étalonnage, EPI, fournisseurs, devoir de vigilance, commandes, Peppol entrant |
| 9 | Ventes et finance | Prospects, devis, commandes, factures Peppol, coûts de revient, écritures, paiements, export comptable |
| 10 | Boutiques et logistique | Caisse, fidélité, réassort, préparation, expéditions, tournées, application chauffeur, EDI |
| 11 | Monde 3D v2 et pilotage | Animations, racks, multi-sites, mode salle de contrôle, tableaux de bord, rapports, runbooks |
| 12 | Durcissement | Test d intrusion, performance, accessibilité, AIPD finalisées, formation, mise en production pilote |
